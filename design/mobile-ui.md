# 奥大小助手移动端设计规范

首页以搜索、二手集市和最新商品为主。四个主导航依次为首页、集市、服务大厅、我的。微信采用原生组件，Android 和 iOS 共用 uni-app x 页面。

## 颜色与尺寸

颜色、字号、间距、圆角和点击尺寸保存在同目录的 `campus.json` 中。品牌标识用 #4A90D9，带白字的主按钮用 #215B98，价格用 #A63E1F。普通文字和次级信息分别用 #172E43、#526778。界面使用设备系统字体。

页面左右各留 16 px，列表列间距 12 px。商品卡保留 4:3 图片，商品名最多两行，价格按完整新西兰元显示，零元显示“免费”。商品状态、品质、地区和时间来自对应公开记录。系统导航及输入框按平台处理安全区。

## 交互

- 集市的筛选先编辑，点“查看结果”才生效。收起面板保留上一次已应用的条件。附近排序要求先选择大概地区。
- 商品详情展示原图和公开商品资料。收藏、站内聊天和购买意向沿用原有登录、归属及商品状态检查。
- 发布前核对标题、金额、分类、地区及照片张数。“继续编辑”保留输入。“确认发布”使用原有上传和发布接口，成功以服务端响应的商品编号为准。
- 服务按出行与搬家、安居与工作、校园互助分组。点分组选择具体分类。服务内容来自该分类的服务目录。
- 加载时显示进度，空列表给出下一步，读取失败提供重试。账号权限及后端配置错误保留原始业务提示。
- 会话里的商品条可以返回关联详情。未读数量、昵称和头像沿用实际会话字段。个人中心只在读取统计后展示成交和在售数量。

## 维护

两个仓库保留同名设计数据和对应的样式入口。更新配色、卡片结构或按钮含义时，在两个 PR 一起审阅。微信卡片位于 `templates/listing-card.wxml`，App 卡片位于 `client/components/item-card/item-card.uvue`。发布前检查 375、390、430 px、长价格、断网、缺图、空列表、键盘和返回编辑。
